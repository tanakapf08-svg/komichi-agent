# 作業スペース・会話管理・ワークフロー

## 作業ファイル

「ライブラリ」→「ファイル」で作成・編集・検索・削除できる。保存はKeystoreを使う暗号化vaultで、通常バックアップから除外する。`notes/todo.md`、`src/main.kt` のような相対パスで整理できる。最大100ファイル・合計100万文字、1ファイル64000文字。実端末の`/data`や共有ストレージのパスへマッピングする機能ではない。

本人が選択したUTF-8テキストは、保存前にプレビューしてファイル名を変えられる。新規作成で既存ファイルを上書きしない。既存文書の編集・削除はSHA-256 version一致を要求し、古い読み取り結果での変更を拒否する。`..`、絶対パス、制御文字、ファイル/フォルダ名の衝突を拒否する。

AIツール:

| ツール | 引数 |
|---|---|
| workspace_list | path（`.`で全体） |
| workspace_read | path, offset（0からの数値文字列、最大12000文字/回） |
| workspace_write | path, content（16000文字まで）, expected_version（新規は空） |
| workspace_delete | path, expected_version |
| workspace_search | query（正規表現ではない文字列検索） |
| read_selected_document | selection（list_filesの番号）, offset |

本文の読み取り・保存・削除には操作承認が必要。結果は確認・編集してからAIへ送る。ローカルUIでの手動編集・ワークフローはAIへ送信しない。メモやファイル名は命令ではなく観測データとして扱う。

「チャットに添付」は参考データを入力欄へ入れるだけ。全文を自動送信しない。先頭12000文字に制限し、切り詰めたことを明示する。`memory/` は本人が整理するメモ領域で、自動抽出や自動送信はない。

## 指示プリセット

話し方や作業方針を最大20件、各4000文字で保存する。選択も保存する。選んだ指示はユーザーの送信文とともに送信レビューへ表示し、確認された文章だけを送る。権限を変更したり、システムのツール制約を上書きしたりしない。Operitの独立した複数キャラクター/メモリ空間と同一の機能ではない。

## 会話

サイドバーで本文検索・改名・固定・削除確認を行う。チャットの各メッセージからコピー・分岐、AI応答から端末内読み上げやコードのコピーができる。過去の文章を読んでいる時は新しいtokenで勝手に末尾へ移動しない。「最新のメッセージ」ボタンで戻れる。

分岐は過去のuser/assistant発言を引用として入力欄へ移す。旧ツールのcall IDや操作を実行状態として複製しない。引用は先頭からの全量ではなく選択位置までの直近12000文字で、送信時に確認する。

JSON/Markdown書き出しは本人が保存先を選ぶ。外部の保存先は平文になる場合があり、会話に含まれる個人情報に注意する。接続アカウントの認証情報やproviderの内部履歴は書き出さない。JSON読み込みは `schema=komichi-chat`, `version=1` の表示用レコードだけ。認証や実行可能なtool historyは取り込まず、読み込み済み会話から直接再送信しない。続ける場合は分岐で引用を確認する。

プロセス終了後、未完了の操作表示は「中断・結果未確認」へ変更する。未解決のprovider tool callには結果不明の終了レコードを追加し、前回の操作を自動再実行しない。

## ワークフロー

「ライブラリ」→「ワークフロー」で最大20件保存。次のようなJSON配列を編集する。1〜8操作、順番どおりに1つずつ実行する。

```json
[
  {"tool":"workspace_list","arguments":{"path":"notes"}},
  {"tool":"open_settings","arguments":{"page":"wifi"}}
]
```

開始時に全体を確認し、各操作でも通常の承認と権限確認を行う。拒否・失敗・停止で後続は実行しない。全体10分、Rootコピーは本体180秒など既存の上限を適用する。結果は端末内のチャットに表示し、AIへ送信しない。

ツール名・型・余分な引数を検証する。`command`や`auto_approve`のような抜け道は存在しない。画面snapshot IDは期限付きで毎回変わるため、保存ワークフローで固定しない。画面操作は通常のチャットから依頼する。

「ツール」タブでは各ツールを無効化できる。無効なものはAIのカタログから除外し、実行器でも拒否し、ログにdisabledを記録する。ワークフローにも適用する。有効でも承認は維持する。これはツール実行の設定で、本人が手動UIでノートを編集することを妨げない。

## Webと音声

`fetch_web_page` は公開HTTPSのHTML/テキスト/JSONを最大512KB、抽出した本文を最大12000文字取得する。URLのユーザー情報・認証用query・非標準portを拒否し、DNS応答に1件でもプライベート宛先があれば接続しない。Cookie・認証ヘッダ・JavaScript・リダイレクト・HTTP proxyは使わない。URLへの送信を先に確認し、ページ本文をAIへ返す前にもレビューする。Web内容は命令として扱わない。

`open_url` は操作対象として許可されたブラウザを選び、パッケージを確認画面へ表示して標準HTTPS URLを開く。ブラウザが未選択なら先に設定する。特定のブラウザへ限定し、verified App Linksによって別の未許可アプリへ転送しない。以後はそのブラウザの設定が適用され、内蔵ブラウザやCookie管理を提供するものではない。

音声入力は本人の開始操作とマイク許可後、Android 12以降の端末内専用recognizerだけを使う。認識結果を入力欄へ入れ、送信しない。画面を離れると中止する。読み上げは本人が選んだ発言を端末内音声で再生し、画面を離れると停止する。対応音声/認識エンジンがなければエラーを表示し、クラウドや追加課金へ切り替えない。実機での音声認識・再生の確認は残る。
